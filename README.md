# Nature Bistro Website

A responsive static website built from the supplied template and the complete Nature Bistro PDF menu.

## Open locally

Double-click `index.html` to open the site in a browser.

## Customize

- Edit categories, dishes, and prices in `menu.js`.
- Edit restaurant text, phone number, and links in `index.html`.
- Replace colors and typography variables at the top of `style.css`.

The menu currently contains 111 entries across 12 categories, including the added Pizzas menu. It uses a spacious multi-column layout on larger screens and includes autocomplete, typo-tolerant search, highlighted matches, price and popularity filters, expandable categories, and quick category links.

The website lists daily opening hours as 11:00 AM to 10:00 PM. The Instagram button currently opens an Instagram keyword search because an exact public profile URL was not supplied; replace its link in `index.html` when the official profile is available.

The site can be published directly with GitHub Pages, Netlify, or any static web host.
